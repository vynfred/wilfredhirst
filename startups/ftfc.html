As Sr. Venture Advisor at FTFC, I built the complete front-end and back-end architecture for the startup advisory platform. The development included creating a responsive web application using modern JavaScript frameworks, implementing user authentication, and designing an intuitive interface for founders to access advisory resources and track their progress.

I integrated the platform with Slack API to enable seamless communication between advisors and founders, creating automated workflows for scheduling sessions, sharing resources, and tracking milestone achievements. The Slack integration allows real-time notifications and creates dedicated channels for each founder cohort, enhancing collaboration and community building.

The entire platform is hosted on Firebase, leveraging its real-time database capabilities, authentication services, and cloud functions for scalable backend operations. This architecture ensures reliable performance, automatic scaling, and secure data management while providing founders with instant access to advisory resources and progress tracking tools.
